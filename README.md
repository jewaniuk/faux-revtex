# faux-revtex

a revtex4-2 look-alike for typst, and an exporter that turns a typst paper written with it into revtex latex for overleaf, arxiv and journals.

early and not usable yet.

```
package/    the typst package (published to typst universe as `faux-revtex`)
exporter/   the rust crate that writes revtex latex (installed separately)
```
